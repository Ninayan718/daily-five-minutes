# 每日 5 分钟 · 读书与实践

一个本地单页应用：每天给你一段书摘、一段深度拆解、一组可执行的实践建议，然后记下你真实用在哪。

## 怎么用

双击 `index.html` 即可，不需要联网、不需要装任何东西。建议加到浏览器书签栏。

**在手机上用**：看下面「手机使用」一节。

```
index.html              单页应用（今日 / 我的记录 / 统计 / 书摘库）
assets/styles.css       样式
assets/app.js           抽取算法、记录、统计、导入导出
assets/icon-*.png       应用图标
manifest.webmanifest    PWA 清单（添加到主屏幕用）
sw.js                   Service Worker，负责离线缓存
data/cards.js           内置书摘库，60 条
dist/                   部署用构建目录，由根目录同步而来
```

## 手机使用

手机上的数据独立存在手机浏览器里，和电脑不互通。要同步就用页脚的「备份 JSON」导出、另一端「导入恢复」。

### 方式一：在线链接（推荐）

HTTPS 部署链接用手机浏览器打开即可。首次打开后内容会被缓存，之后断网也能看。

添加到主屏幕，用起来跟 App 一样：

- **iPhone / iPad（Safari）**：打开链接 → 底部分享按钮 → 「添加到主屏幕」
- **安卓（Chrome）**：打开链接 → 右上角菜单 → 「添加到主屏幕」/「安装应用」

### 方式二：同一 WiFi 访问电脑

```
cd 项目目录
npx serve .            # 或 python3 -m http.server 8000
```

手机连同一个 WiFi，访问 `http://<电脑的局域网 IP>:端口`。IP 在「系统设置 → Wi-Fi → 详细信息」里查看。电脑关机或换网络就断。

### 方式三：把文件传到手机

用隔空投送或任意方式把整个文件夹传到手机，用支持本地文件的浏览器打开 `index.html`。缺点：部分浏览器会清理 localStorage，长期用不推荐。

## 更新部署版本

改完代码后同步到 `dist/` 再部署，并把 `sw.js` 顶部的 `CACHE` 版本号加一（如 `read5-v1.1.0`），手机才会拉到新版本：

```
rm -rf dist && mkdir -p dist/assets dist/data
cp index.html sw.js manifest.webmanifest dist/
cp assets/*.css assets/*.js assets/*.png dist/assets/
cp data/cards.js dist/data/
```

## 每天的流程

1. 打开页面，看到当天的卡片
2. 花 5 分钟读：书摘 → 它到底在说什么 → 工作怎么用 → 生活怎么用 → 今日微行动
3. 当天找机会真的用一次
4. 回到「我的记录」，用三段式记下来：场景 / 我怎么做的 / 结果+反思

四个视图：

- **今日**：当天卡片，「换一条」可以换（换掉的当天不会再出现）
- **我的记录**：三段式输入 + 全部历史记录
- **统计**：阅读天数、连续天数、实践率、领域分布、用得最多的方法
- **书摘库**：60 条内置条目，支持搜索、按领域和年代筛选，可手动设为今日卡片

## 每日卡片怎么选出来的

按日期做确定性计算，同一天在任何设备上打开都是同一张卡，不会随机漂移。

六个领域（决策 / 沟通 / 效率 / 管理 / 心理 / 财富）按顺序轮换，每条用完后不再出现，60 天走完一轮后自动重新开始。

## 关于书摘的版权

库里的书摘全部是**精炼转述**，不是原文整段复制。每条控制在百字以内，其余部分（内核、机制、误区、用法）都是独立的解读内容。

你自己添加条目时也建议这样处理：转述核心意思 + 写下你的理解，而不是大段粘贴原文。

## 添加自己的书摘

在「书摘库」点「+ 添加书摘」，只需填写书名、原文（作者可选）。点击「生成 AI 补全提示词」，复制提示词发给你使用的 AI，再把 AI 返回的 JSON 粘贴并导入。检查或修改领域、背景、核心观点、机制、适用边界、工作与生活建议、微行动后，加入书摘库。

此流程不内置 AI 服务，也不会自动上传原文；需要你自行把提示词和原文发给所选择的 AI。AI 生成内容可能有误，请核对书中语境和实践建议后再保存。原文仅整理自己有权使用的内容，避免粘贴整章或过长段落。

「工作怎么用」支持用箭头分隔触发条件和具体做法：

```
跨部门求助前 → 先给对方他正好需要的数据
汇报开场 → 先抛结论再给理由
```

## 数据存在哪

全部存在浏览器的 localStorage 里，不上传任何地方。

**清浏览器数据会丢**，所以页脚提供了「备份 JSON」和「导入恢复」。建议每月备份一次，或者直接用「导出 Markdown」把实践记录存进你的笔记软件。

## 关于「实践率」

实践率 = 有记录的天数 ÷ 阅读天数。

这个数字比「读了多少本」重要得多。只读不用，读再多也不会改变任何事。
